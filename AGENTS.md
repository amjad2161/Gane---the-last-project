# G.A.N.E Agent Execution Policy

Preserve all approved features, architecture, accuracy, privacy, safety and verification criteria. Optimize credit consumption per VERIFIED completed task, not by hiding work or weakening quality.

- Inspect only relevant code, diffs and docs; reuse still-current findings and persistent project checkpoints.
- Use deterministic scripts for repeatable scanning, filtering and validation. Save full logs; surface concise excerpts and evidence paths.
- Load specialist skills on demand. Run parallel agents only for independent bounded tasks with justified benefit; prevent repeated investigations.
- Batch independent read-only calls. Check pending status before retrying. Keep changes reversible and testable.
- Test affected modules during iteration, then all required integration, numerical, safety, security, performance and release checks before claiming success.
- Prioritize GNSS/fusion numerical integrity, degraded navigation, spoof/jam detection, offline resilience, ETA regression, accessibility and RTL.
- Do not enable paid fast tiers or third-party traffic proxies without verifying their cost, security and recovery characteristics.
- Record measured token/credit usage when available; never invent savings.

This complements, rather than supersedes, higher-priority user or project requirements.
